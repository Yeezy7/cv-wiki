# 多模态

多模态学习（Multimodal Learning）致力于让模型同时理解和处理多种模态的信息（文本、图像、音频等）。

## 学习路线

多模态方向建议先补齐视觉和语言两边的基础，再学习模态对齐、视觉编码器、视觉定位和多模态应用工程。

### 第一阶段：视觉与语言基础（1-2 周）

**学习内容：**
- CNN、ViT、图像分类、目标检测的基本任务形式
- Transformer、Tokenizer、Embedding、文本编码

**阶段产出：**
- 能说明图像特征和文本特征为什么需要映射到同一语义空间
- 能区分图像分类、图文检索、视觉问答、目标定位等任务

### 第二阶段：图文对齐与 CLIP（1-2 周）

**学习内容：**
- [CLIP](/ai-wiki/multimodal/clip) — 对比学习、图文匹配、零样本分类
- 正负样本构造、相似度矩阵、温度系数、双塔模型

**阶段产出：**
- 能解释 CLIP 的训练目标和零样本分类流程
- 能复现一个图文检索或零样本分类小实验
- 能说明对比学习和普通分类训练的差异

### 第三阶段：视觉 Transformer（1 周）

**学习内容：**
- ViT、Patch Embedding、位置编码、视觉特征提取
- CNN 与 Transformer 在视觉任务中的差异

**阶段产出：**
- 能解释 ViT 如何把图片变成 token 序列
- 能说明 ViT 为什么依赖数据规模和预训练

### 第四阶段：Grounding 与视觉定位（1-2 周）

**学习内容：**
- Grounding、目标指代、区域描述、开放词表检测
- 图文区域对齐、框/掩码/文本之间的监督信号

**阶段产出：**
- 能解释“看图问答”和“视觉定位”的任务边界
- 能分析定位错误是视觉检测问题、语言理解问题还是对齐问题

### 第五阶段：多模态大模型应用（2 周）

**学习内容：**
- VLM、图像理解、OCR、文档理解、多模态 RAG
- 输入预处理、图片分辨率、上下文组织、评估集设计

**阶段产出：**
- 能设计一个图像问答或文档理解 Demo
- 能说明多模态系统在幻觉、引用、延迟和成本上的工程风险

### 面试检查点

多模态面试通常会从 CLIP 切入，再追问 ViT、Grounding、VLM 应用和工程评估。建议每个阶段都准备“核心公式/训练目标、典型模型、线上应用问题”三套答案。
