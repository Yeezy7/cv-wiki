## 简介

CNN，全称 **Convolutional Neural Network，卷积神经网络**，是计算机视觉中最基础的深度学习结构之一。

![CNN 架构示例](/images/multimodal/cnn/cnn_architecture_cs231n.jpeg)

*CNN 架构示例：输入图像经过多层卷积、池化后，最终通过全连接层输出分类结果（来源：CS231n）*

它主要用于从图像中提取特征，例如边缘、纹理、形状和语义信息。CNN 曾长期作为图像分类、目标检测、图像分割、人脸识别、OCR 等任务的基础模型。

在多模态任务中，CNN 也可以作为图像编码器，将图像转成视觉特征，再与文本特征进行融合。

---

## 核心思想

CNN 的核心是：

> 用卷积核在图像上滑动，从局部区域中提取特征。

它主要有三个特点：

|特点|说明|
|---|---|
|局部连接|每次只看图像的一小块区域|
|参数共享|同一个卷积核在整张图像上重复使用|
|层级特征|浅层提取边缘纹理，深层提取语义信息|

普通全连接网络处理图像时参数量很大，而且会破坏图像的空间结构。CNN 通过卷积操作保留了图像的二维结构，因此更适合视觉任务。

---

## 卷积操作

卷积层会使用一个小的卷积核，例如 `3×3`，在输入图像或特征图上滑动，并对局部区域做加权求和。

简单理解：

```text
卷积 = 用一个小窗口在图像上滑动，提取局部特征
```

对于输入特征图 `X` 和卷积核 `K`，输出可以表示为：

```text
Y(i, j) = Σ X(i + m, j + n) · K(m, n)
```

在 PyTorch 中，卷积层通常写作：

```python
nn.Conv2d(
    in_channels=3,
    out_channels=64,
    kernel_size=3,
    stride=1,
    padding=1
)
```

含义是：输入通道数为 3，输出通道数为 64，卷积核大小为 `3×3`。

---

## 输出尺寸计算

二维卷积的输出尺寸为：

```text
H_out = floor((H_in + 2P - K) / S) + 1
W_out = floor((W_in + 2P - K) / S) + 1
```

其中：

|符号|含义|
|---|---|
|`K`|卷积核大小|
|`S`|stride，步长|
|`P`|padding，填充|
|`H_in, W_in`|输入高和宽|
|`H_out, W_out`|输出高和宽|

例如输入是 `32×32`，卷积核为 `3×3`，`stride=1`，`padding=1`，则输出仍然是 `32×32`。

---

## 参数量计算

卷积层参数量为：

```text
参数量 = K × K × C_in × C_out + C_out
```

其中：

- `K` 是卷积核大小；
    
- `C_in` 是输入通道数；
    
- `C_out` 是输出通道数；
    
- 最后的 `C_out` 是 bias 参数。
    

例如：

```python
nn.Conv2d(3, 64, kernel_size=3)
```

参数量为：

```text
3 × 3 × 3 × 64 + 64 = 1792
```

## 常见组件

### 1. 卷积层

用于提取局部特征，是 CNN 的核心。

常见卷积核：

|卷积核|作用|
|---|---|
|`1×1`|改变通道数、融合通道信息|
|`3×3`|最常用，兼顾效果和计算量|
|`5×5`|感受野更大，但计算量更高|

### 2. 激活函数

卷积之后通常接激活函数，引入非线性能力。

常用的是：

```python
nn.ReLU()
```

常见结构：

```text
Conv → ReLU
```

或：

```text
Conv → BatchNorm → ReLU
```

### 3. 池化层

池化用于降低特征图尺寸，减少计算量。

常见池化：

|类型|说明|
|---|---|
|Max Pooling|取局部最大值|
|Average Pooling|取局部平均值|
|Global Average Pooling|对整张特征图求平均|

## 感受野

感受野指的是特征图上一个位置能够看到的原始图像区域。

浅层网络感受野小，主要看到边缘、纹理；深层网络感受野大，可以看到目标整体结构。

多个小卷积可以扩大感受野。例如两个 `3×3` 卷积叠加，可以获得类似 `5×5` 的感受野，同时参数量更少，并且多了一次非线性变换。

---

## 简单 PyTorch 示例

```python
import torch
import torch.nn as nn


class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()

        self.net = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),

            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),

            nn.Flatten(),
            nn.Linear(64 * 8 * 8, num_classes)
        )

    def forward(self, x):
        return self.net(x)


model = SimpleCNN()
x = torch.randn(4, 3, 32, 32)
y = model(x)

print(y.shape)  # torch.Size([4, 10])
```

输入图像大小为 `32×32`，经过两次 `2×2` 池化后：

```text
32×32 → 16×16 → 8×8
```

因此全连接层输入维度是：

```text
64 × 8 × 8
```

---

## 工程注意点

1. `padding=1, kernel_size=3` 可以在 `stride=1` 时保持特征图大小不变。
    
2. 下采样太多会丢失小目标信息，检测、分割任务中要特别注意。
    
3. BatchNorm 对 batch size 比较敏感，小 batch 训练时可能不稳定。
    
4. `1×1` 卷积常用于通道降维、升维和特征融合。
    
5. CNN 不是只能做分类，也常用于检测、分割、OCR、人脸识别等任务。

## 面试问题

### Q1：CNN 为什么适合处理图像？

因为图像具有局部空间结构。CNN 通过局部连接提取局部特征，通过参数共享减少参数量，并通过多层堆叠逐步学习从边缘到语义的层级特征。

---

### Q2：卷积层相比全连接层有什么优势？

卷积层参数更少，能够保留图像的空间结构，并且适合提取局部特征。全连接层会把图像展平成向量，容易破坏空间关系，而且参数量更大。

---

### Q3：`1×1` 卷积有什么用？

`1×1` 卷积主要用于改变通道数和融合通道信息。它不改变空间尺寸，但可以在通道维度上做线性组合，常用于降维、升维和减少计算量。

---

### Q4：什么是感受野？

感受野是特征图中某个位置对应到输入图像中的区域大小。感受野越大，模型能看到的上下文越多；感受野太小，可能无法理解完整目标。

---

### Q5：CNN 和 ViT 有什么区别？

CNN 更强调局部特征和参数共享，具有较强的图像归纳偏置。ViT 基于自注意力机制，更擅长建模全局关系，在大规模预训练和多模态模型中更常见。

---

## 小结

CNN 的核心是卷积操作。它通过局部连接、参数共享和层级特征提取，使模型能够高效处理图像数据。
