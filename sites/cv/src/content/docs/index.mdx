## 学习路线

这条路线适合从深度学习基础进入计算机视觉工程实践。建议每个阶段都保留一个可复现的小实验，而不只是阅读概念。

### 第一阶段：深度学习基础（1-2 周）

**学习内容：**
- [CNN 基础](/ai-wiki/cv/basics/cnn) — 理解卷积、池化、感受野和参数共享
- [BatchNorm](/ai-wiki/cv/basics/batchnorm) — 理解训练稳定性、训练/推理统计量差异
- [激活函数](/ai-wiki/cv/basics/activation) — 掌握 ReLU、Sigmoid、GELU 等非线性函数
- [损失函数](/ai-wiki/cv/basics/loss-functions) — 理解分类、回归和检测任务的损失选择

**阶段产出：**
- 能手写一个小型 CNN 训练 MNIST 或 CIFAR-10
- 能解释卷积输出尺寸、感受野、BatchNorm 训练/推理差异
- 能把一个概念整理成 1-3 段可口述面试回答

### 第二阶段：经典图像处理（1 周）

**学习内容：**
- 滤波、边缘检测、阈值分割、形态学操作
- OpenCV 基础 API 和常见图像增强流程

**阶段产出：**
- 能用 OpenCV 完成图像去噪、边缘提取和连通域分析
- 能说明传统图像处理与深度学习方法各自适合的场景

### 第三阶段：目标检测（2-3 周）

**学习内容：**
- [目标检测综述](/ai-wiki/cv/detection/overview) — 建立检测任务、数据标注和模型输出的整体框架
- [YOLO 系列](/ai-wiki/cv/detection/yolo) — 理解一阶段检测器、Anchor、特征金字塔
- [NMS](/ai-wiki/cv/detection/nms) — 掌握后处理去重逻辑
- [mAP](/ai-wiki/cv/detection/map) — 理解 Precision、Recall、AP 和 COCO 指标

**阶段产出：**
- 能训练或复现实例级的 YOLO 检测实验
- 能解释一阶段/两阶段检测器、Anchor-Based/Anchor-Free、NMS 和 mAP
- 能定位检测效果差时是数据、标注、阈值还是模型问题

### 第四阶段：图像分割（1-2 周）

**学习内容：**
- [图像分割综述](/ai-wiki/cv/segmentation/overview) — 区分语义分割、实例分割、全景分割
- U-Net、DeepLab、Mask R-CNN、Mask2Former 等代表方法

**阶段产出：**
- 能完成一个语义分割小实验并可视化 mask
- 能解释像素级损失、类别不均衡和边界质量问题

### 第五阶段：工程部署（1-2 周）

**学习内容：**
- ONNX、TensorRT、量化、剪枝、蒸馏
- 端侧推理、服务端推理、批处理吞吐和延迟优化

**阶段产出：**
- 能把一个 CV 模型导出为 ONNX 并完成推理验证
- 能说清楚精度、速度、显存、吞吐之间的工程权衡

### 面试检查点

每学完一个阶段，都准备三类材料：核心概念的口述答案、一个可复现实验、一个工程问题复盘。这样学习路线会自然沉淀成面试素材。
