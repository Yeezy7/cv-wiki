## 简介

在 PyTorch 中，神经网络通常通过 `torch.nn` 模块构建。

最常见的写法是继承 `nn.Module`：

```python
import torch
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        ...

    def forward(self, x):
        ...
```

其中：

```text
__init__：定义网络中有哪些层；
forward：定义数据如何经过这些层。
```

---

## nn.Module 是什么

`nn.Module` 是 PyTorch 中所有神经网络模块的基类。

一个模型、一个线性层、一个卷积层、一个激活函数，都可以看作是 `Module`。

例如：

```python
nn.Linear(784, 10)
nn.ReLU()
nn.Conv2d(3, 16, kernel_size=3)
```

这些都是 PyTorch 提供好的模块。

自定义神经网络时，通常把多个模块组合起来：

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.layer1(x)
        x = self.relu(x)
        x = self.layer2(x)
        return x
```

## 一个最小神经网络

下面是一个用于分类任务的简单神经网络。

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()

        self.fc1 = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x
```

这个模型的结构是：

```text
输入 784 维
-> Linear(784, 128)
-> ReLU
-> Linear(128, 10)
-> 输出 10 维
```

如果用于 MNIST 分类：

```text
784 = 28 × 28
10 = 10 个数字类别
```

## forward 的作用

`forward` 定义前向传播过程。

也就是：

```text
输入数据 x 如何一步步变成模型输出。
```

例如：

```python
def forward(self, x):
    x = self.fc1(x)
    x = self.relu(x)
    x = self.fc2(x)
    return x
```

使用模型时，一般不直接调用 `forward`，而是写：

```python
output = model(x)
```

PyTorch 会自动调用：

```python
model.forward(x)
```

所以推荐写法是：

```python
output = model(x)
```

而不是：

```python
output = model.forward(x)
```

## nn.Linear

`nn.Linear` 表示全连接层。

```python
nn.Linear(in_features, out_features)
```

例如：

```python
nn.Linear(784, 128)
```

表示：

```text
输入特征维度是 784；
输出特征维度是 128。
```

它执行的是线性变换：

```text
y = xW^T + b
```

输入输出形状示例：

```python
layer = nn.Linear(784, 128)

x = torch.randn(32, 784)
y = layer(x)

print(y.shape)
```

输出：

```text
torch.Size([32, 128])
```

其中：

```text
32 是 batch size；
784 是输入维度；
128 是输出维度。
```

## 激活函数

如果只有线性层，多个线性层叠加后仍然相当于一个线性变换。

因此神经网络通常需要加入非线性激活函数。

最常见的是 `ReLU`：

```python
nn.ReLU()
```

使用：

```python
x = self.fc1(x)
x = self.relu(x)
x = self.fc2(x)
```

它的作用可以简单理解为：

```text
让模型具备表达非线性关系的能力。
```

## nn.Sequential

如果网络是简单的顺序结构，可以使用 `nn.Sequential` 简化代码。

普通写法：

```python
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x
```

可以改写为：

```python
class MLP(nn.Module):
    def __init__(self):
        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.net(x)
```

`nn.Sequential` 会按照传入顺序依次执行每一层。

适合简单的顺序网络。

model = MLP()

## 模型参数

模型中的可学习参数可以通过 `parameters()` 获取。

```python
model = MLP()

for param in model.parameters():
    print(param.shape)
```

例如 `nn.Linear(784, 128)` 中有：

```text
weight: [128, 784]
bias: [128]
```

训练时，优化器需要拿到模型参数：

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=1e-3
)
```

这里的 `model.parameters()` 就是把模型中需要更新的参数交给优化器。

## 模型输入输出形状

写神经网络时，最容易出错的是 shape。

例如 MLP 输入需要是二维张量：

```text
[B, 784]
```

其中：

```text
B 是 batch size；
784 是特征维度。
```

但图像通常是四维张量：

```text
[B, C, H, W]
```

如果要把 MNIST 图像输入 MLP，需要先展平：

```python
x = x.view(x.size(0), -1)
```

或者：

```python
x = torch.flatten(x, start_dim=1)
```

示例：

```python
def forward(self, x):
    x = torch.flatten(x, start_dim=1)
    x = self.net(x)
    return x
```

这样可以把：

```text
[B, 1, 28, 28]
```

变成：

```text
[B, 784]
```

---

## 完整示例

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = torch.flatten(x, start_dim=1)
        return self.net(x)


model = MLP()

x = torch.randn(32, 1, 28, 28)
output = model(x)

print(output.shape)
```

输出：

```text
torch.Size([32, 10])
```

含义是：

```text
输入 32 张图片；
每张图片输出 10 个类别的分数。
```

## 和训练循环的关系

模型定义完成后，会在训练循环中被调用。

```python
model = MLP()
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for images, labels in train_loader:
    pred = model(images)
    loss = loss_fn(pred, labels)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

其中：

```text
pred = model(images)：前向传播；
loss_fn(pred, labels)：计算损失；
loss.backward()：反向传播；
optimizer.step()：更新模型参数。
```

## 常见注意点

### 1. 不要忘记继承 `nn.Module`

推荐：

```python
class MyModel(nn.Module):
    ...
```

这样 PyTorch 才能正确管理模型参数和子模块。

---

### 2. 不要忘记 `super().__init__()`

推荐：

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        ...
```

如果忘记调用，模型中的子模块和参数可能无法被 PyTorch 正确注册。

---

### 3. 层要定义在 `__init__` 中

推荐：

```python
self.fc = nn.Linear(784, 10)
```

不推荐在 `forward` 中反复创建层：

```python
def forward(self, x):
    fc = nn.Linear(784, 10)
    return fc(x)
```

因为这样每次前向传播都会创建新的层，参数无法正常训练。

---

### 4. 注意输入 shape

如果模型要求输入是：

```text
[B, 784]
```

但实际输入是：

```text
[B, 1, 28, 28]
```

就需要先展平：

```python
x = torch.flatten(x, start_dim=1)
```

---

### 5. 分类模型最后通常不需要 Softmax

如果使用：

```python
nn.CrossEntropyLoss()
```

模型最后一层通常直接输出 logits：

```python
nn.Linear(128, 10)
```

不需要手动加 `Softmax`。

因为 `CrossEntropyLoss` 内部会处理对应的计算。

## 小结

PyTorch 中定义神经网络的核心是 `nn.Module`。

重点记住：

```text
__init__ 定义网络层；
forward 定义前向传播；
model(x) 会自动调用 forward；
model.parameters() 返回可训练参数；
optimizer 通过 model.parameters() 更新模型。
```

最常用模板：

```python
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.net(x)
```

掌握 `nn.Module` 后，就可以开始编写自己的 MLP、CNN 或其他神经网络模型。
