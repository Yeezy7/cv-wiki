# 大语言模型

大语言模型（Large Language Model, LLM）是自然语言处理领域的突破性技术，通过大规模预训练学习语言的深层规律。

## 学习路线

大语言模型方向建议按“架构原理 → 训练机制 → 应用增强 → 对齐评估 → 工程落地”的顺序推进。不要一开始就只背模型名称，先把 Transformer 和生成过程讲清楚。

### 第一阶段：Transformer 基础（1-2 周）

**学习内容：**
- [Transformer](/ai-wiki/llm/transformer) — 自注意力机制、多头注意力、位置编码、编码器-解码器结构
- Token、Embedding、语言建模目标、Teacher Forcing

**阶段产出：**
- 能手推 Self-Attention 的 Q、K、V 计算流程
- 能解释为什么 Transformer 适合并行训练
- 能说清楚 Decoder-only、Encoder-only、Encoder-Decoder 的适用任务

### 第二阶段：预训练与生成机制（1-2 周）

**学习内容：**
- 预训练目标、语料清洗、Tokenizer、上下文窗口
- Greedy Search、Beam Search、Top-k、Top-p、Temperature 等解码策略

**阶段产出：**
- 能解释模型为什么会生成重复、幻觉或不稳定答案
- 能根据任务选择合适的解码参数
- 能读懂基础训练日志中的 loss、perplexity 和评估指标

### 第三阶段：微调技术（1-2 周）

**学习内容：**
- 全参数微调、LoRA、QLoRA、Adapter
- 指令微调、数据配比、过拟合、灾难性遗忘

**阶段产出：**
- 能说明 LoRA 的低秩分解思想和参数效率优势
- 能设计一个小规模指令微调数据集
- 能判断什么时候需要微调，什么时候只需要 Prompt 或 RAG

### 第四阶段：RAG 应用（1-2 周）

**学习内容：**
- 检索增强生成（Retrieval-Augmented Generation, RAG）
- 文档切分、Embedding、向量数据库、召回、重排、引用答案

**阶段产出：**
- 能搭建一个最小可用的知识库问答流程
- 能分析“检索不到、检索错、生成错”分别该如何排查
- 能说明 RAG 与微调的边界

### 第五阶段：对齐、评估与工程化（2 周）

**学习内容：**
- RLHF、DPO、偏好数据、拒答策略、安全评估
- 推理加速、KV Cache、量化、并发、成本控制

**阶段产出：**
- 能解释 RLHF 和 DPO 的核心差异
- 能设计基础评测集，覆盖正确性、稳定性、安全性和延迟
- 能把一个 LLM 应用从 Demo 推进到可观测、可回滚的工程服务

### 面试检查点

LLM 面试最常追问“为什么这样设计”和“线上出了问题怎么查”。每个阶段都准备一个原理问题、一个实验问题、一个工程排障问题，会比单纯背名词更稳。
